APIs para Plataformas Móviles

API de ejemplo para usar en la materia Proyecto de Desarrollo de Software para Plataformas Móviles. Las respuestas se entregan exclusivamente en formato JSON.

Comidas

GET /comidas

Devuelve el listado de comidas típicas con filtros por categoría, búsqueda por texto, ordenamiento y paginación.

Parámetros

Parámetro Ubicación Tipo Valores válidos Por defecto Descripción
grupo Query string salados, dulces, bebidas — Filtra por categoría.
busqueda Query string Texto libre — Busca en id, nombre, descripción, tipo, región, etiquetas o ingredientes.
ordenar_campo Query string id, nombre, grupo, tipo, region, descripcion nombre Campo para ordenar.
ordenar_sentido Query string asc, desc asc Sentido del ordenamiento.
pagina Query number Entero ≥ 1 1 Número de página solicitada.
limite Query number Entero ≥ 1 5 Cantidad de elementos por página.

Ejemplo en JavaScript

const res = await fetch('https://api.tehuel.com.ar/comidas?grupo=salados&limite=5');
const { data, total, pagina, paginas } = await res.json();
console.log(total, data);

Contador

GET /contador/:nombre

Obtiene el valor numérico actual del contador especificado por :nombre. Si no existe, retorna 0.

Parámetros

Parámetro Ubicación Tipo Requerido Descripción
:nombre Ruta (Path) string Sí Identificador único del contador a consultar.

Ejemplo en JavaScript

const res = await fetch('https://api.tehuel.com.ar/contador/visitas');
const { count } = await res.json();
console.log(count); // 0

Ejemplo de respuesta

{
  "count": 0
}
POST /contador/:nombre

Incrementa en 1 unidad el valor del contador especificado por :nombre y devuelve el nuevo total acumulado.

Parámetros

Parámetro Ubicación Tipo Requerido Descripción
:nombre Ruta (Path) string Sí Identificador único del contador a incrementar.

Ejemplo en JavaScript

const res = await fetch('https://api.tehuel.com.ar/contador/visitas', {
  method: 'POST'
});
const { count } = await res.json();
console.log(count); // 1

Ejemplo de respuesta

{
  "count": 1
}
